# M4.0 — OCCT capability probe (throwaway spike scaffold)

Knowledge spike, not production code (build-plan M4.0). The artifact is the capability
map in `docs/subsystems/GEOMETRY.md`; these scripts are the evidence trail and get
deleted/productionized in M4.1+. PEP 723 scripts — run with `uv run scripts/spike-m4.0/<probe>.py`
from the repo root (results land in `scripts/spike-m4.0/results/`).

**Synthetic fixtures only.** Every probe reads `/fixtures/cad` — self-authored synthetic
STEP files generated by `gen_fixtures.py` from OCCT primitives, whose dimensions are
public in their filenames and in `goldens.json`. The probes print those known dimensions
by design (the printed values ARE the spike's findings). This does not touch the repo
logging rule ("never log customer PII or CAD/print contents"): these scripts must never
be pointed at customer CAD, run in production, or wired into the app's logging path.
The production GeometryService (M4.1+) logs job status only, never geometry values.

Probes: (a) dims/signature · (b) sheet-metal bends/unfold · (c) milling holes/pockets ·
(d) tube classification + lathe stock · (e) XCAF `decompose_bom` · (f) BRepMesh
tessellation · `smoke.py` = import/parse path check.
