Overview

Design B — the loud, high-contrast direction: heavy black display type, saturated colored section heads, a lime highlighter, 3D-tilted mockups, black interstitials. Derived structurally from fulcrumpro.com.

Measured from the live fulcrumpro.com DOM on 2026-07-18. Fulcrum is Webflow (motion is JS/IX2; many extra webfonts load but go unused). Substitute Hanken Grotesk for the licensed Gilroy, recolor to Tolera, and drop retro artefacts / certs / copy. Purple = AI-only; every honesty gate applies.

Radius · container · buttons · shadows · motion

Radius & container

  • Dominant card radius 20px (also 24, 12, 10, 6, 4, 2; pills 30–32).
  • Container max ≈ 1296px; mockups bleed past one edge.
  • Buttons are pills: black bg / white text r20, 20px/500; secondary tinted bg / black text r24.

Shadows & motion

  • Resting card: rgba(0,0,0,.16) 4px 4px 17px (directional).
  • Floating mockup: deep multi-layer stack up to 0 631px 252px rgba(0,0,0,.01).
  • Motion: 0.2s ease workhorse, 0.4s opacity, 0.5s color; Webflow IX2.
  • matrix3d tilts · ScrollTrigger pinned boards · explore-more slider · constellation particles · static lime marker span.

Reduced-motion-safe; degrade to static on md-. Only keyframes are spin + menuIn.

Adopt vs. replace

Adopt

  • Type rhythm: 72/700 hero + ~52/600 colored heads (-0.75px), 500 navy body
  • 20px card radius + pill buttons
  • ≈1300px container with edge-bleed mockups
  • 0.2s/0.4s ease motion; directional soft shadow

Replace

  • Gilroy → Hanken Grotesk
  • Every hex → Tolera's recolored green/orange/blue + lime
  • All copy, retro artefacts, certs, assets
  • Drop funding-round palette & ISO/ITAR/CMMC badges

Keep the feel: loud saturated section heads, lime highlighter emphasis, 3D-tilted mockups bleeding off one edge, black constellation interstitials alternating with white.
