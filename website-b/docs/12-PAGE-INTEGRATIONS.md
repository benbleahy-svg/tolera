# 12 — Integrationen page (`/integrationen`) — Design B

Fulcrum's Integrations page (`/fulcrum-integrations`): a "Let It Flow" hero with floating data-flow mockups, a filterable category + logo grid, "are we missing one / join the network" pair, and an FAQ. Reference: `docs/reference/fulcrum/pages/integrations-*.jpg`.

**Legal gate (shared with Design A, positioning §8.3):** every third-party logo needs per-logo permission (nominative use). Ship **text chips** until cleared; standards marks (XRechnung/Peppol) are safest.

## Sections

1. **Hero** — eyebrow („Integrationen", color-highlight) + `hero` headline (PROPOSED: „Alles fließt zusammen.") + subhead (connect accounting/CAD/logistics; remove data gaps, manual entry, paper) + „Vertrieb kontaktieren" CTA. Floating callout/data-flow mockups (§5.3) on the right showing „an DATEV übergeben", „XRechnung erzeugt", etc. (our own mock UI, Tolera-true flows).
2. **„Alles verbinden"** — intro paragraph + **category filter pills** (Buchhaltung · CAD/CAM · Versand · Steuer · Nesting · Sonstige — Tolera-relevant categories) + a **logo/text grid** of integrations. DACH-relevant set: DATEV, SOLIDWORKS, SAP Business One, XRechnung/ZUGFeRD/Peppol, DHL/DPD/GLS. Each cell = logo (once cleared) or text chip. Note which are "live" vs "planned" honestly.
3. **„Fehlt eine?" / „Werden Sie Partner"** — the two-card pair: request-an-integration (→ sales) + partner-with-us (→ partnerships). Tolera-true.
4. **FAQ** — open API?, plug-and-play?, missing integration? — honest answers (Tolera's API status is an `OPEN:` if not yet public; don't claim an open API that doesn't exist).
5. **Closing CTA** + footer.

## Rules
- No logo ships without permission; text chips until then. Never imply a live integration that isn't (mark "geplant").
- API/open-API claims must match reality (`OPEN:` if unsure).
- Structure from reference; palette/fonts/copy ours.

## Acceptance
Parity with `integrations-*.jpg` at 3 breakpoints (hero + category filter + grid + missing/partner pair + FAQ); category filter actually filters the grid; every integration labelled live/planned truthfully; no uncleared logos in the bundle.
