# 11 — Einführung & Support page (`/einfuehrung`) — Design B — Fulcrum "Launch" equivalent

Fulcrum's Launch page (`/erp-implementation`) sells its onboarding as a differentiator: dedicated in-house team, fixed one-time fee, weeks-not-years, support included forever. For Tolera this maps to an **„Einführung & Support"** page — but tuned to Tolera's reality (pre-pilot, self-serve trial, small team). Reference: `docs/reference/fulcrum/pages/launch-*.jpg`.

**Honesty gate:** Fulcrum cites specifics (hundreds of shops, "2-hour avg response, 3.6× faster", an annual user conference, a community hub). Tolera has **none of these yet**. Do not copy them. Build the page structure with Tolera-true content; leave numeric/social-proof slots empty until real. Route: DE `/einfuehrung`, EN `/en/onboarding`.

## Sections (structure from Fulcrum, content from Tolera)

1. **Hero** — team-photo cards floating around a centered eyebrow („Tolera Einführung") + `hero` headline (PROPOSED: „Kein monatelanges ERP-Projekt.") + subhead („Feste Einführung, kein Beraterstundensatz." — only if true) + CTA. Team photos: use real Tolera team photos or omit (never stock/fake).
2. **„In Wochen startklar, nicht in Jahren"** — a dark comparison card (Tolera vs. altes ERP) with an „Zeitplan schätzen" affordance. Keep the comparison generic (status quo), not a named competitor (positioning Decision #1).
3. **Phased plan** — `PHASE 1–4` cards (Define → Build → Validate → Launch equivalent): „Verstehen → Aufsetzen → Prüfen → Loslegen", each 1–2 sentences. This is honest and useful even pre-pilot.
4. **„Kein Schulungshandbuch nötig"** — shop-simplicity block + a mini Job-Tracking/operator mockup („Bedienoberfläche testen →" links to the stage page).
5. **Integrations tie-in** — „Mit Ihren Tools verbunden" + link to /integrationen. Tolera-true integrations only (DATEV, XRechnung — see 12).
6. **Support model** — „Support inklusive" with the three-ways-to-engage structure IF Tolera offers them; otherwise a single honest support statement. **No invented response-time metrics.** No user-conference/community claims until they exist.
7. **Closing CTA** — „Lassen Sie uns Ihre Einführung übernehmen." + „Demo vereinbaren" + trust strip.
8. Footer.

## Rules
- Every proof point must be Tolera-true; empty-slot the ones that aren't (team photos, metrics, community, conference).
- Pricing posture stays consistent with positioning: 14-day trial, keine Kreditkarte, indicative tiers — a "fixed one-time launch fee" is a Fulcrum model, **not** Tolera's; don't assert it unless Benjamin confirms.
- Structure/energy from Launch reference; palette/fonts/copy ours.

## Acceptance
Parity with `launch-*.jpg` at 3 breakpoints (floating team cards, phase cards, support block, CTA); zero unverifiable claims; flag any Tolera-model decisions (fixed fee? support tiers?) as `OPEN:` for Benjamin.
