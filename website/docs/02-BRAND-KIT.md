# 02 — Brand Kit (proposal, v1)

**Status:** PROPOSED by Claude (2026-07-17). Benjamin approves/edits before build. Everything here is swappable; the token names in 01-DESIGN-SYSTEM stay stable so a brand change is a one-file edit.

## 1. Brand idea

Tolera sells **speed with precision** to people who live in tolerances (the name already says it: *Toleranz*). The brand should read like a very good technical drawing: calm, exact, daylight. Not "SaaS for SaaS people" — no dark mode, no glow, no hype vocabulary (positioning §6 deviations).

Register: plain technical German, Sie-Form, verbs over adjectives (liest, erkennt, kalkuliert, markiert, schlägt vor).

## 2. Wordmark & logo (direction, needs final art)

- Wordmark: **"tolera"** lowercase, Inter Display SemiBold, letter-spacing -1.5%, `ink`.
- Mark concept (pick one, commission/draw as SVG):
  1. **Tolerance band** — two thin parallel horizontal strokes with a bolder stroke between them (the ± band around a nominal line). Minimal, ownable, meaningful. *(recommended)*
  2. Chamfered **t** — the letter t with a 45° chamfer, drafting-style.
- Clear space = height of the "t"; min size 24px; single-color `ink` (inverse `paper`); never gradients.
- Favicon/app icon: the mark alone on `paper`, `r-lg` container.
- **DPMA/EUIPO screening before launch** (positioning §8.2) — applies to Tolera + Lens/Kontur/Kalk/Vergabe.

## 3. Color

Exactly the token palette in 01-DESIGN-SYSTEM §2. Brand hierarchy:

- **Ink on paper is the brand.** Black-ish text, white ground, hairlines.
- `accent` steel blue `#1D5FD6` = precision/links/data. Sparingly (≤1 accent element per viewport).
- `ai-purple` `#7C3AED` @55% = *only* AI suggestions ("purple = KI schlägt vor" — same grammar as the product's AI-Governor).
- Trust strip may use the 🇩🇪 flag emoji per locked copy; no other decorative color.

## 4. Type

Inter Display (headlines) + Inter (text) + Source Serif 4 (manifesto/quotes) + JetBrains Mono (technical micro-labels). All open-licensed (OFL), self-hosted — no licensing dependency, no Google Fonts CDN (GDPR).
