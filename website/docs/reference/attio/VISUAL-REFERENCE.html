Overview

Design A — the quiet, light, hairline "technical drawing" direction, derived structurally from attio.com.

Everything below is measured from the live attio.com DOM (Tailwind v4 @theme tokens + computed styles) on 2026-07-18 — exact numbers for scale, rhythm, and motion. Because Design A is also Tailwind v4, most tokens lift 1:1 into our theme. Adopt the scale, spacing, radii, shadow recipe and easings; replace every hex with Tolera's kit and the licensed Tiempos serif with an OFL serif. A reference pixel never outranks a Tolera spec or the positioning doc.

Shadows & motion

Shadows — layered, sub-6% alpha, cool-tinted "float"

Big card: 0 1px 2px rgba(28,29,31,.05), 0 2px 4px -1px rgba(28,29,31,.02), 0 4px 8px -2px rgba(28,29,31,.03), 0 8px 16px -4px rgba(28,29,31,.04), 0 16px 32px -8px rgba(28,29,31,.05), 0 32px 64px -8px rgba(28,29,31,.06) + inner 0 0 0 1px rgba(255,255,255,.2)
Small card: 0 2px 8px rgba(11,13,24,.04), 0 16px 40px rgba(11,13,24,.08)

Motion — default 0.15s cubic-bezier(.4,0,.2,1)

  • ease-out cubic-bezier(0,0,0,1) · ease-in-out (emphasized) cubic-bezier(.2,0,0,1)
  • ease-in-out-cubic cubic-bezier(.65,0,.35,1) · ease-out-cubic cubic-bezier(.33,1,.68,1)
  • ease-in-out-expo cubic-bezier(1,0,0,1) (big reveals) · ease-reveal cubic-bezier(0,0,.58,1)
  • dropdown 0.3s · dialog 0.2s · nav 0.2s · pulse 2s · spin 1s.
  • Scroll-reveal is the home page's core device (opacity/translate + pinned 0.8s width/height). Rebuild reduced-motion-safe — this is why the hero/mid-bands don't flatten in the full-page stitches.

Adopt vs. replace

Adopt 1:1

  • The full type scale + tracking
  • 4px spacing base
  • Radius scale (cards 12–16px, buttons 6–8px)
  • Container band (~1280px max)
  • Named easings + 0.15s default
  • Multi-layer soft-shadow recipe

Replace

  • Every hex → Tolera ink/paper + restrained accents (purple = AI only)
  • Tiempos serif → OFL Newsreader / Source Serif for italic pull-quotes
  • All copy & assets → Tolera's (from positioning doc)
  • Keep accents as sparse as Attio does
