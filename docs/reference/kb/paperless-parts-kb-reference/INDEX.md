# Paperless Parts — Knowledge Base Reference

**Purpose.** Complete, structured capture of the Paperless Parts public knowledge base (186 articles), organized as a working reference for **building a DACH-region clone / improved version of Paperless Parts**. Use it for two things:

1. **UI/UX reference** — how each screen, tool, and workflow looks and behaves (screenshots are linked inline from Paperless Parts' public CDN, so a vision-capable agent can open them).
2. **Logic, reasoning & context** — the rules, data model, pricing language (P3L), interrogation logic, and feature intent behind each workflow.

## How this is organized

- `articles/<area>/<slug>.md` — one Markdown file per article with YAML front-matter (`title`, `slug`, `source`, `topic`) and a link to the live source.
- `index.html` — a single browsable, grouped HTML version of the entire KB (open in a browser to read everything with images).
- Articles are grouped into 14 functional areas, numbered in a logical build order.
- Images use Paperless Parts' original public URLs (stable, unsigned). Text is faithful Markdown converted from the source HTML.

> Captured 2026-06-19. Source: https://help.paperlessparts.com/  · Unofficial reference for internal product work.
