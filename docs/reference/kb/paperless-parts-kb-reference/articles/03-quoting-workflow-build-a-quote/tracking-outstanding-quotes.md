# Tracking outstanding quotes

> Source: https://help.paperlessparts.com/s/article/tracking-outstanding-quotes  
> Topic: Quoting Workflow (Build a Quote)

Once you [send a quote](https://help.paperlessparts.com/s/article/sending-quotes), navigate to the Quotes page to track views and quickly follow up with your buyer.

When a digital quote is viewed for the first time, the "Last Viewed" column will populate with metrics on who interacted with the quote link and when. Select the timestamp in the "Last Viewed" column for more information.

*![](/servlet/rtaImage?eid=ka0Ns0000004LM1&feoid=00N5G00000WB8Hk&refid=0EMNs00000BeGXZ)*

*Note*: These metrics only represent interactions with the link to the digital quote. If you included a quote PDF in the quote-send email, interactions with that file will not be included in these numbers.

Select **Resend quote**in the bottom right to reach back out to your buyer. You can also perform this action from [the Actions menu](https://help.paperlessparts.com/s/article/quote-actions) in the Build-a-Quote page.

*Tip*: Want to create an email template for resending quotes? Create and edit templates from [your organization's settings](https://app.paperlessparts.com/settings/digital_quote/email_templates).
