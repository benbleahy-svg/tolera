# Ensure digital quote access

To ensure you can access Digital Quotes, please whitelist the following domain names:

digital-quote.comwww.digital-quote.comapi.digital-quote.comrfq.digital-quote.com These services do not have fixed IP addresses. Paperless Parts serves some content using Amazon's CloudFront Content Delivery Network (CDN) and other content from Amazon's GovCloud "us-gov-west-1" data center.  Amazon publishes its CloudFront IP ranges here: http://d7uri8nf7uskq.cloudfront.net/tools/list-cloudfront-ips Amazon publishes all of its IP addresses at the link below, including IP ranges for "us-gov-west-1": https://docs.aws.amazon.com/general/latest/gr/aws-ip-ranges.html Please note that many websites besides Paperless Parts run on these IP ranges.

# Ensure access to Paperless Parts

To ensure that users on your network can access all Paperless Parts features and that our team can help with support requests, you will need to allow HTTPS traffic (TCP port 443) to the following fully qualified domain names. Note that most of these services use content delivery networks and load balancers, so the corresponding IP addresses will change frequently.
