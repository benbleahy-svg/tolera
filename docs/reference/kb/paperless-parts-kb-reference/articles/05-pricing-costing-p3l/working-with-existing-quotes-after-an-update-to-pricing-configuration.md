# Working with existing quotes after an update to pricing configuration

> Source: https://help.paperlessparts.com/s/article/working-with-existing-quotes-after-an-update-to-pricing-configuration  
> Topic: Pricing, Costing & P3L

To preserve the integrity of your existing quotes, changes made to your Paperless configuration will not be reflected in draft quotes or when revising an old quote. All quotes created after the configuration update will reflect the changes.

If you want to apply the updates to quotes you're currently working on - or revisions of old quotes - here are a few steps that you can take to apply configuration changes.

## **Quote items without overrides or manual operations**

1. Open the quote item you want to update and scroll down to the Process section.
2. Click Actions and select Regenerate Operations.
  1. This will delete all operations, overrides, and manual operations and repopulate the from the latest version of the selected process.

#

## **Quotes with overrides or manual operations**

#### To update a single quote item:

1. Open the quote item you want to update and scroll down to the Process section.
2. Click Actions and select Refresh Pricing.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/6328adc5e5ea7f482dc3cb95/file-Gbq3gXWYST.png)

#### To update multiple quote items at once:

1. Open the quote.
2. Select the checkbox to the left of the search bar in the left side panel menu.  ![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/6328aebf656bd979ec836095/file-BFPgFIiaXN.png)
3. Click Actions and select Bulk Refresh Pricing.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/6328ae71894a5358bdd778fe/file-2unJhWoTWU.png)

#### After a pricing refresh (for each line item)

1. If operations were removed from a process or deleted entirely:
  1. Manually remove any old operations
2. If new pricing items were created
  1. Manually remove old pricing items
3. If new pricing items were created
  1. Manually add any pricing items that might be needed to correctly price the quote
