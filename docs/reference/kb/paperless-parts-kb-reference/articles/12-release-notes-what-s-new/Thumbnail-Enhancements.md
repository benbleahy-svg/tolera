# Part Thumbnail Enhancements - August 21, 2023

> Source: https://help.paperlessparts.com/s/article/Thumbnail-Enhancements  
> Topic: Release Notes (What's New)

Today we have released an update giving thumbnail images greater detail and better contrast. This update also causes thumbnails to generate up to 50-70% faster, which will improve the load time of large assemblies. The appearance of thumbnails has been changed to remove smooth shading and harsh shadows to softer, even lighting with rounding highlights and some model lines - similar to how they are rendered in many CAD programs today*This change applies to new file uploads only. Thumbnails will not be regenerated for existing part files in Paperless Parts.
