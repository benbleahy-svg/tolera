# Assembly Table Updates - July 31, 2023

> Source: https://help.paperlessparts.com/s/article/Assembly-Table-Updates  
> Topic: Release Notes (What's New)

Today we announce several updates to the Assembly Component Table that will make navigating and reordering BOMs easier than ever.

- Part Breadcrumbs
- Unique URLs for Child Components
- Drag-and-Drop Rearrangement of Components in Assembly BOMs

# Part Breadcrumbs

 Previously, Assembly Tables lacked an easy way to navigate between different levels of a BOM. Now, breadcrumb trails at the top of the assembly table indicate where you are in an assembly, and enable you to easily navigate between parent or sibling components in a BOM.

# Unique URLs for Child Components

Now, each component in a BOM has a unique URL, so that when collaborating with other estimators on a large assembly, you can send a link directly to the part you would like to reference.

# Drag-and-Drop Rearrangement of Components in Assembly BOMs

 When the order of the parts in a BOM is important, you can now ungroup child parts in the assembly table and click and drag parts into the desired order.
