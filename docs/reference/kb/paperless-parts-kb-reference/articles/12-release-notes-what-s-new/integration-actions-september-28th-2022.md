# Integration actions - September 28th, 2022

> Source: https://help.paperlessparts.com/s/article/integration-actions-september-28th-2022  
> Topic: Release Notes (What's New)

# What's new?

If you have an integration with another software system, you can now monitor and control the behavior of that integration directly from Paperless Parts with our new **Integration manager.**To access your integrations, navigate to the **Integrations**section of your settings:

**![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/63b86c6ce8beff1be5c66949/file-JffJsW5HpD.png)**Each software integration will have its own **Integration manager**, from which you can view a log of previous **Integration actions**or request new actions (such as "Export order" and "Import contact").

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/63b86d43e0d50f555584034a/file-IvkFY72xFG.png)For a more detailed walkthrough of this new feature, check out our [Integration manager help article](https://help.paperlessparts.com/s/article/integration-manager) or [reach out](mailto:mailto:support@paperlessparts.com) to a member of our team.
