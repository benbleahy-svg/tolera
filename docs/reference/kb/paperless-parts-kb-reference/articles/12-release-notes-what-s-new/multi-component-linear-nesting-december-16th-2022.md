# Multi-component linear nesting - December 16th, 2022

> Source: https://help.paperlessparts.com/s/article/multi-component-linear-nesting-december-16th-2022  
> Topic: Release Notes (What's New)

# What's new?

We've added **l****inear nesting** to our multi-component nesting module. This powerful feature set enables you to optimize the cost of material and labor of linear metal parts by predicting shared cutting patterns of many components out of the same tube, pipe, channel, or bar.

**Note:** The linear nesting module requires account-specific configuration and setup. To learn more, or to inquire about adding nesting to your account, [reach out to our Support team](mailto:mailto:support@paperlessparts.com).

With linear nesting, you can now:

- Browse all linear-nesting-compatible parts within a single quote
- Select components you'd like to nest together and fill out a form to control the nest
- Browse key results from generated nests, including length usage, cost distribution, and required stock quantity

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/63b8790fd0b6de7e3be2a800/file-sJjzdVdgSF.png)![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/63b8791dd0b6de7e3be2a801/file-EYjRYjelFX.png)

Generating nests will then optimize nest-eligible operations within the quote.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/63b87a00f6d1fb09b86ce931/file-1RDYtafK2T.png)

As part of this release, you can also view the results of a tube metal interrogation directly from the Build a Quote page for linear models.
