# Updated Quotes and Orders Dashboards - August 3rd, 2023

> Source: https://help.paperlessparts.com/s/article/Updated-Quotes-and-Orders-Dasboards  
> Topic: Release Notes (What's New)

We've visually updated the Quotes and Orders dashboards! New Quotes Dashboard:Old Quotes Dashboard:

The updated dashboards work mostly the same as the old dashboards, just with an updated design that visually aligns with tables elsewhere in the platform and consolidates row height.

The minor functionality changes include:

- Remove the quote contact, salesperson, and estimator email addresses (this information was repetitive since the person’s name is also displayed, and took up significant space within those columns)
- Update the loading behavior for Overdue and Due Soon draft quotes:
  - Limit the number of Overdue and Due Soon quotes that load when you click on the Draft tab to 40 each. If there are more than 40 Overdue / Due Soon quotes, you can scroll and click to load more
  - Display the number of Overdue and Due Soon quotes that are being displayed (defaulted to 40) out of the number that exist
  - Note: Filter and search results will still include all draft quotes, regardless if the quote is hidden in the initial table load
  - This was done to improve the load performance of the Draft tab and enable you to easily scroll beyond Overdue / Due Soon quotes
