# New contacts page - June_July 2022

> Source: https://help.paperlessparts.com/s/article/new-contacts-page-june-july-2022  
> Topic: Release Notes (What's New)

###

### We have made changes to the Contacts tab! Learn more about the contacts page [here](https://help.paperlessparts.com/s/article/accounts-and-contacts). Here is a summary of the updates:

###

### **Improved visibility**

We have added a table interface that displays key information about each contact and account without requiring the user to click into the item:

**![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/62c753c3d242501d78c624b9/file-sGB6ZZT8j5.png)**

Download a csv of all of your contacts or accounts:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/62c7540cc74a080359c87a33/file-MJwhuSzzqZ.png)

###

Bulk update accounts and contacts

After selecting specific contacts or accounts, a user can bulk update the selected items.

For contacts, users can bulk update salesperson and account:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/62a293c05732000792523631/file-gUGDitcJl8.png)

For accounts, users can bulk update type, salesperson, payment terms, tax exempt status, credit card acceptance status, and PO acceptance status:

Bulk delete contacts or accounts
