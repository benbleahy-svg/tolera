# Supporting files update - March 17th, 2022

> Source: https://help.paperlessparts.com/s/article/supporting-files-update-march-17th-2022  
> Topic: Release Notes (What's New)

Within a quote item, the display for supporting files has been updated. Now, only the first 10 files will be listed. If there are more than 10 files, click on "See all" to show the list of all supporting files:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/6232a31c2ce7ed0fb0916553/file-Qq6OFgHX1r.png)

In the drawer, you will be able to view, swap, download, or remove the files:

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/6232a3782ce7ed0fb0916556/file-ifWNjg2l30.png)
