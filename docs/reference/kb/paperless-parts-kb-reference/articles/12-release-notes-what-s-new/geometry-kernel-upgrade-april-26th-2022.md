# Geometry kernel upgrade - April 26th, 2022

> Source: https://help.paperlessparts.com/s/article/geometry-kernel-upgrade-april-26th-2022  
> Topic: Release Notes (What's New)

## What's new in v24.0.0

Our engineering team has brought yet another **major version release** to you in the month of April. This release features an upgrade to our core geometry kernel and other supporting libraries.

This upgrade has significantly improved the speed, memory usage, stability, and security of our entire file processing pipeline. Users can expect an average of 25% reduction in both milling and lathe interrogation times, as well as reduced time to first render in the viewer for new file uploads. Along with the speed increases, we are now up to date on the latest versions of several critical software packages. These new versions give us a stronger security positioning and open up new ways for our engineering team to deliver impactful solutions to our customers.
