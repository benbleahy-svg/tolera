# Part Setup tool

> Source: https://help.paperlessparts.com/s/article/Part-setup-tool  
> Topic: Part Analysis & Interrogation

## Quickly enter part information across line items and components

The Part Setup tool allows you to quickly enter part number, revision, description, export-controlled, process, material, and finish across line items and components.

Changes in the part setup tool live-sync with the open quote, allowing you to work from both screens simultaneously.

This tool may be useful as an estimator, stepping through parts to evaluate process; or may be valuable to anyone setting up quotes, transcribing key information before an estimator begins quoting.

### Accessing the Part Setup tool

The Part Setup tool can be accessed from the part viewer when opened from an active quote.

It notably **cannot**be accessed from the part library viewer; since Process, Material, and Finish are quote-specific fields.

## Entering part and quote fields

Within the "Part fields" tab, the Part Setup tool allows you to enter part number, revision, description, export-controlled (for line items only), process, material, and finish. When [Wingman](https://help.paperlessparts.com/s/article/wingman-assistance) identifies a likely value for one of these fields, it will be suggested here.

Notably, process, material, and finish are *quote-specific fields--*meaning if you re-use this part across quotes, you'll see different values in these fields. This also means that as you enter these values, your corresponding router will be generated.

For more on these fields, see:

- Entering part number, revision, and description
- Assigning a process, material, and finish

## Stepping through line items/components and focusing on prints

At the bottom of either tab, you can find two buttons that will step you to the next/previous assembly component (if within an assembly) or next/previous line item (if in a non-assembly component, or at the end/start of an assembly component).

- Pro Tip #1: You can operate this workflow without touching your mouse! Simply select the first field, then press tab to step through each field and enter on the "next" button--which will return you to the first field of the next part.
- Pro Tip #2: Keep the "BOM" tab open while stepping through assemblies to easily see where your focused part is within the assembly structure.
