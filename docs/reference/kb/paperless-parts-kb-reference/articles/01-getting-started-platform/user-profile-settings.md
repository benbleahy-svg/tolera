# User Profile

Start by navigating to the settings page by clicking on your shop's name at the top right corner, and scroll down to "User Profile". Or click [this link](https://app.paperlessparts.com/settings/accounting/banking_information)when signed into Paperless Parts.![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/61532e040754e74465f14770/file-B8Vu98SSka.png) The User Profile is very straightforward. Here you can set your profile information (First Name, Last Name), change your password, enable 2-factor authentication, and track login activity. Not only are we ITAR compliant and secure, but we have also provided the necessary security measures to keep each account safe, and authenticate each user.

### **1. Change Password**

Update the password by providing the current password and the new one. Choose a password that cannot be easily guessed. Each password must be at least 8 bytes of case-sensitive characters, numbers, and special characters.

If you have forgotten your password, you can reset it [here](https://app.paperlessparts.com/reset_password).

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/6151c37100c03d672075ac9a/file-dPOYeF41rQ.png)

### **2. Two-Factor Authentication**

 This is an extra layer of security for when logging in, requiring verification from your mobile device. Each time you log out and log back in, it will prompt input of the unique code generated by your authentication app.

Read [this resource](https://help.paperlessparts.com/s/article/two-factor-authentication-2fa) to learn how to set up 2FA!

### **Reset 2FA**

In the event where you no longer have access to the authenticator app (e.g. deleted, new phone... etc.), this can be resolved by disabling and re-enabling 2FA. Reach out to your admin to reset 2FA from the team's page. The admin will need to navigate to the team's page, or by clicking [this link](https://app.paperlessparts.com/team) and click the edit pencil next to the team member who needs the reset. Admin should now be able to disable 2FA, and you will be able to set up 2FA again by following the steps above.

If you are the admin and cannot log in due to 2FA, please reach out to [support@paperlessparts.com](mailto:mailto:support@paperlessparts.com).

### ![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/61532f3f0754e74465f1477d/file-5wZeEMwIfL.png)**3. Login Activity**

Track all previous and concurrent activity. There will be information on access type: what device and browser were used, the location by IP address, and the date of the login. It is recommended to verify these logins daily to protect your account. If there is any suspicious activity, change your password and log out of all sessions.
