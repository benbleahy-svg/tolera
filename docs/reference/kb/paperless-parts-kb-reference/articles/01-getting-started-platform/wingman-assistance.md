# Wingman: Paperless Parts' AI Assistance

> Source: https://help.paperlessparts.com/s/article/wingman-assistance  
> Topic: Getting Started & Platform

## What is Wingman?

"Wingman" is the name given to the collection of secure, CMMC-compliant AI-supported features that help you get more accurate quotes out the door faster with less risk. When you see features that are purple and have the "sparks" icon next to them, you know you are interacting with a feature utilizing Wingman's intelligence to provide assistance for your workflow.

In the below example, you can see that Wingman has extracted a Part Number and Revision from a print and is now suggesting those values beneath their respective fields.

## Interactions with AI Assistance in Paperless Parts

Assistance can appear in the application in multiple states. While the specific look and behavior of each field may slightly differ, this guide will help you understand how to interpret our presentation of assistance.

## Eligible

When Wingman can offer a value for a field, but it has not yet been accepted or rejected, it will appear with two hollow sparks and a purple highlight. The field will be left blank if the user does not interact with the assistance.
![](/servlet/rtaImage?eid=ka0Ns0000009U3h&feoid=00N5G00000WB8Hk&refid=0EMNs0000038XI3)![](/servlet/rtaImage?eid=ka0Ns0000009U3h&feoid=00N5G00000WB8Hk&refid=0EMNs0000038XI4)

## Accepted

When a field has been set using assistance, it will show up as a checkmark with a spark. This indicated that the value in this field matches what Wingman suggested. Sometimes, Wingman's suggestions will automatically be accepted. Otherwise, you will need to accept a suggestion manually.

![](/servlet/rtaImage?eid=ka0Ns0000009U3h&feoid=00N5G00000WB8Hk&refid=0EMNs0000038XI5)

## Rejected

When Wingman has offered a value for a field, but the user rejects it, the field will indicate this with two grey sparks with a cross line through it. The user can undo this action, go back into the field, and either accept its assistance or enter a new value.
![](/servlet/rtaImage?eid=ka0Ns0000009U3h&feoid=00N5G00000WB8Hk&refid=0EMNs0000038XI6)

## Automated Actions

Assistance can sometimes take the form of actions we take on the user's behalf. When this occurs, the application will notify the user what actions were taken.

In the below example, Wingman was used to create 12 line items from the contents of an RFQ.![](/servlet/rtaImage?eid=ka0Ns0000009U3h&feoid=00N5G00000WB8Hk&refid=0EMNs0000038XI7)

## Does Wingman use AI?

Sometimes. Some Wingman features utilize AI, and others will use less sophisticated technology to help you complete tasks within Paperless Parts. Regardless, your data is safe in Paperless Parts per our [AI Guiding Principles](https://www.paperlessparts.com/artificial-intelligence-in-paperless-parts/).

## Where is Wingman Used?

This is a non-exhaustive list of fields and actions in Paperless Parts that utilize Wingman:

- Contact
- Account
- RFQ Received Date
- Salesperson
- Bulk Line Item Creation
- Bulk File Assignment
- Part Number, Revision, and Description
- Material, in the Process, Material, and Finish flow
