**Exporting quotes**

To export multiple quotes as a CSV, navigate to the Quotes page and click the three dots next to the [Saved View title](https://help.paperlessparts.com/s/article/Saved-Views) to open the actions menu. Select **Download view CSV**to download the results of the Saved View (including all visible columns and quotes or line items that match the filter results), or **Download current results**if you have made any recent changes to the filters or column selection.

# **Export orders**

Like quotes, you can [export multiple orders into a CSV](https://help.paperlessparts.com/s/article/filtering-quotes-and-orders#h.nal92oz4yrow4) by applying a filter on the Orders page and selecting **Export**.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/61b8d4a051b4c537989a0109/file-0W3TziC6v8.png)

The CSV will include the following information for each line item in each order:

- Order Number
- Order Status
- Order Dates
- Deliver by Date
- Related Quote Number
- Account Name
- Contact First/Last Name and Email
- Salesperson Full Name and
- Part Name (this is the filename, not the part number)
- Line Item Number
- Line Item Quantity
- Line Item Unit Price
- Line Item Total
- Tax Total
- Shipping Total
- Order Grand Total
- Payment Method
- PO Number
- Order Payout to Supplier
- Process Name
- Material Name
- Finishes
- Shipping Address
- Ships On Date

**Exporting individual quotes**

To download a specific quote and/or its files, navigate to your desired quote and click **Actions** at the top of the quote. From there, you can download the quote's **Files**or the entire quote as a**PDF,****CSV**and/or**Excel****.** Learn more about each export option (and quote actions) [here](https://help.paperlessparts.com/s/article/quote-actions).

**Exporting individual orders**

To download the part files associated with an order, navigate to the order and select **Download Files**. This action will create a zip folder of each part's primary and supporting files.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/61fda79e39e5d05141b66aeb/file-PTz4Hk1qlP.png)Scroll to the bottom of the order page to download any other relevant order files such as the Purchase Order (if uploaded), Order Confirmation PDF, Router, Invoice, Packing Slip, and the Certification of Conformance. ![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/61fda7c968cd260cc2d38229/file-YtLJoUgrQE.png)

# **Exporting query results from Analytics**

All results from table view queries can be exported as a . CSV file from the Query Builder page. Click on the 3 lines, and **Edit Query** to be taken to the Query Builder. The view will always default to **Number.**Click on this and change it to **Table.** Above the resulting table click **Download as CSV.**

*Note:* This is part of Advanced Analytics, which is an enterprise-level feature. If you have any questions, need assistance with these exports, or are interested in getting this feature, please reach out to your CSM or contact [our Support team](#).

# **Export contacts/accounts**

To export your contacts and accounts, navigate to the Contacts page and select Download CSV. Below is a list of what can be found in the export, depending on which group you choose to export.

More information about this update can be found here: [New Contacts Page](https://help.paperlessparts.com/s/article/new-contacts-page-june-july-2022).

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/62cdcf54d242501d78c63b36/file-Mz3SN8eds5.png)

[https://help.paperlessparts.com/s/article/new-contacts-page-june-july-2022](https://help.paperlessparts.com/s/article/new-contacts-page-june-july-2022)**Accounts CSV Export :**

- Account Name
- Type
- Phone & Phone Ext
- Address 1 & 2, City, State, Country, Zip Code
- Salesperson Email
- Salesperson First & Last Name
- ERP Code
- Website
- Notes
- Payment Terms & Payment Terms Period
- Credit Line, Tax Rate,
- Tax Exempt, Purchase Orders (True or False)

**Contacts CSV Export:**

- Account Name
- First & Last Name
- Email
- Notes
- Phone & Phone Ext
- Salesperson Email
- Salesperson First & Last Name
- Address 1 & 2, City, State, Country, Zip Code

*Note*: If there is something that you would like to export that was not listed in this article, we may be able to offer a more custom export via our Analytics Page and table queries. Almost everything you see on the platform is a data point that Advanced analytics can be queried on (with a few exceptions). Please see our [Analytics Overview](https://help.paperlessparts.com/s/article/analytics) resource for more information on how to set these queries. Note that you must have Advanced Analytics to perform exports and custom queries. Reach out to Support if you have any questions or need assistance with setting up a dashboard or query.

We are unable to utilize Advanced Analytics to aggregate operation level information (variables within operations, run/setup times). If you need this more granular data, please reach out to your Customer Success Manager to scope out a request for a custom snapshot export, or if you are interested in adding Advanced Analytics to your current plan.
