# External collaboration - customer perspective

> Source: https://help.paperlessparts.com/s/article/external-collaboration-customer-perspective  
> Topic: Setup, Config & Org Settings

This resource walks through external file sharing and collaboration from the customer/vendor perspective.

####

#### On this page

- Create a part viewer account
- Navigating a part viewer account
- External Collaboration

# Create a part viewer account

When a shop shares a file with you, you'll receive an email invitation to collaborate with them in Paperless Parts. If you do not have an account, click **Create Secure Account** to set up your part viewer account. Once logged in, you will be taken directly to the shared file.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/61b8f263372a8f501c4a1ec7/file-GeIcsbGlaw.png)

# Navigating the part viewer account

The search anything bar at the top will follow you throughout the platform, and allow you to quickly find any part. Search by file name, part numbers, and revision numbers.

## Dashboard Page

The main dashboard houses all notifications, such as new replies and shares or requests for access. Notifications can alternatively be accessed via the Bell icon in the top left corner.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/61b8f4fae5e5185a647d4a5c/file-IrPf9x877b.png)

## Parts Page

Upload your own files and find them in the **Team Parts** library. Click **Select Parts** from the Team Parts tab to either **Archive** or **Merge together as Supporting Files** (this converts a part to be a supporting file and merges it with a primary file)

The **Shared with Me** library houses all parts that a shop has shared with you.

The **Archived** is your deleted files from the teams' parts library.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/61b8f827a5e184696a17ab7e/file-bzDUKU5AYO.png)

## Part viewer

Click on any part to be taken to the Part Viewer. Here you can view the file(s), features, and begin collaborating. Please see the following resources for more information: [Collaborating with your Team as a Part Viewer Account Member](https://help.paperlessparts.com/s/article/collaborating-with-your-team-as-a-part-viewer-account-member) and our [Part Viewer Help Page.](https://help.paperlessparts.com/category/159-training---part-viewer)

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/61b8f7ee689c5f49b2d19870/file-wXFtZADmEr.png)Team page

Manage your team on this account: invite new members, and update existing ones. Read more about the Team page: [Teams Page Part Viewer Perspective](https://help.paperlessparts.com/s/article/managing-your-team-as-a-part-viewer-user).

## Settings page

Update your user profile, accounting, and company settings from this page

- **User profile** allows you to update your name, password, [enable 2-factor authentication](https://help.paperlessparts.com/s/article/two-factor-authentication-2fa) and track login activity. See this resource for more information about the user profile (*note* article is for Paperless Quoting Users): [User Profile](https://help.paperlessparts.com/s/article/user-profile-settings)

- Navigate to **C****ompany settings** to change the name of your company. This will update the name that appears at the top right and will be reflected in future external collaboration messages.

![](https://s3.amazonaws.com/helpscout.net/docs/assets/5be4842c04286304a71c0d57/images/61ce11b1d1a2f12bbe21fc10/file-JR0mAsspLM.png)

# External collaboration

Once your account has been created, any future shares will notify you by email. Click **Access File**to start collaborating!
