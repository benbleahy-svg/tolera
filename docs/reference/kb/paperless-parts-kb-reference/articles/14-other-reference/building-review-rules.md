# Review rule building guide

> Source: https://help.paperlessparts.com/s/article/building-review-rules  
> Topic: Other / Reference

# Overview

In this guide, you’ll learn how to build rules to flag the most critical requirements from your prints and models with Requirements Review.

To learn more about Requirements Review, see [this overview](https://help.paperlessparts.com/s/article/requirements-review).

---

# Concepts

Review rules are configured by connecting **signals**--conditions applied to data from prints, models, document text, and high-level line item and quote data--to **resolutions**, decisions and actions taken in response to what was found.

As an example, consider a tight true position tolerance on a print. In this case, the signals and resolutions might be:

- Signal(s): When there is one or more tight true position tolerances in a print
- Resolution(s): No-quote or send for outside processing

## Available signals

You can build signals from the following file, line item, part, and quote data:

- **GD&T and callouts,**including holes, sinks, bores, control frames, dimensions, and tolerances
- **Document text** (from any.pdf, .tiff, .doc, .docx files), simple keywords with case matching or complex patterns with Regular Expression (regex).
- **Interrogation results,**including exactly sheet metal, tube laser, milling, and turning high-level properties, features, and feedback (DFM warnings).
  - *Note rules based on these signals will only trigger after the relevant interrogation is run, either manually or from setting process / adding operations.*
- **Presence of files by type,**including exactly whether a part has a model or print
- **Part properties,**including exactly high-level geometric attributes (which will be auto-filled by models but can be manually entered from prints), is assembly (T/F), and is root (T/F).
- **Line item information,**including exactly the minimum and maximum requested quantity.
- **Quote information,**including exactly the account you are quoting for.

The signal picker will provide descriptions for each of its options, helping you understand what to pick.

## Available resolutions

- **No-quote**- set the line item of that component’s status to “no-quote”.
- **Assign line item estimator**- assign the line item of that component to the specified estimator.
- **Set process**- set the process of that component to the specified process.
- **Add operation**- add the specified operation to the bottom of the router.
- **Resolve (custom label)**- resolve the item without changing anything else. Displays with the specified custom label, effectively capturing real-world tasks or decisions that don’t align with available resolutions such as contacting a vendor or getting approval from a stakeholder.

# Building your first rule

In this tutorial, we’ll build a rule to flag all tight tolerances on prints--showing you how to add signals, apply thresholds to print data, connect multiple conditions, add your preferred resolutions, and add a default assignee responsible for addressing the rule.

Make sure you have the "edit" permission for "processes", which you'll need to build rules.

## Getting to the rules builder

To begin, head into a quote or the quote part viewer and **open the Review Items panel.**

![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1hc5)

Next,**at the bottom right, click “create rule”**--this will bring up the rule creation dialogue.

![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1ibN)

## Setting up the rule

Now, let’s **name this rule “All tight dimension tolerances”**:

![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1ipu)

Next, **click on the empty box below “signals”,**which will bring up the signal picker:

![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1k0T)

From here, make the following selections in order:

- **GD&T and callouts → Tolerances → Length tolerances -> Smallest (upper or lower) → Less than or equal to**

![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1gbC)

This should now have added the signal with a threshold of 0. **Select the text box and enter the tolerance**your shop considers to be tight,such as 5 thou (0.005 inches).

![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1Rp5)

If you need to use metric units, you can switch the units at the top of the signal.

Next, click “OR”--this will add a new case.![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1kLR)

Within this new case, repeat the above process but for **Diameter**tolerances, setting the threshold too.

- **GD&T and callouts → Tolerances → Diameter tolerances -> Smallest (upper or lower) → Less than or equal to**

![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1kYL)

Finally, click “OR” one more time and repeat the above for **Radii**tolerances, setting the threshold as well.

- **GD&T and callouts → Tolerances → Radii tolerances -> Smallest (upper or lower) → Less than or equal to**

![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1kWj)

With all of our signals complete, we can now add resolutions. Select the resolution box:

![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1nkj)

Then, add your preferred resolutions; in the below, we selected “resolve” and added the custom label “Outside processing” as well as selected “no quote”. These resolutions will become options for the end user to pick one of to resolve the rule.

![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1SjW)

Finally, add an assignee for the rule to be default-assigned to a specific person, notifying them whenever it is caught and directing them to enter the quote and resolve the item, and **hit "create rule" at the bottom right to complete the rule.**

![](/servlet/rtaImage?eid=ka0Ns0000009E5N&feoid=00N5G00000WB8Hk&refid=0EMNs00000K1nsn)

## Testing the rule

Once you’ve built this rule, upload a print with any tight tolerances to a new line item. Make sure to wait for AI to finish processing (indicated by a spinner in the quote part viewer or found in files container).

Once AI finishes processing, if that print has those tolerances, the rule should appear in the review items panel!

If the rule doesn’t appear, check what was found in the Found in Files panel, as well as what the default units are (top right of the viewer). If a dimension wasn’t found, you can label it yourself to add it to the list.

If none of these tips helped, reach out to [support@paperlessparts.com](mailto:support@paperlessparts.com) for assistance.

# Tips and tricks

1. **Make sure to include all types of linear dimensions when desired:**when looking for tight tolerances or dimensions of a certain size, you must explicitly include all three of length, diameter, and radii dimensions or tolerances (with an “OR” between them) to catch all three kinds with a certain size or tolerance.
2. **You can apply multiple text keywords in the same box:**when adding text keywords, press tab to continue entering multiple keywords, saving the need to apply an “OR” between them.
3. **Make sure to use “OR” when looking for*****any*****of the conditions, instead of*****all*****of them:**when you use “AND” between signals, ALL of them must be found. When you use “OR”, each can be matched independently (but will still match if multiple are true).
