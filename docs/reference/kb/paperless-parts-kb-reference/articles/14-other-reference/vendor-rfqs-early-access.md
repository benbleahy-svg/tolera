# Vendor RFQs (Beta)

> Source: https://help.paperlessparts.com/s/article/vendor-rfqs-early-access  
> Topic: Other / Reference

Learn how to send material RFQs and compare quotes directly from Paperless Parts.

This feature is **early access only and** not yet complete. It is only currently available to a small subset of Paperless Parts users.

## Quick start guide

To request a material price while quoting:

1. Navigate to the line item.
2. Add the "Real-time pricing" material operation.
3. Click the badge in the operation description to open the Real-time pricing window.
4. Use dropdown menus to search for a specific material by:
  1. Material
  2. Alloy
  3. Shape and dimensions
  4. Material specifications
5. Select the stock you would like quoted (max one from Online Metals and one from TK).
6. Select Configure stock to review stock information and parts per stock for each make quantity. Make any necessary overrides and click Request quote.
7. Select the pricing you want to use and click Save changes to confirm.

 To configure real-time pricing:

1. Navigate to Real-time Pricing Settings.
2. Enter the email address associated with your Online Metals and/or TK account.
3. Save changes.

## FAQ

### How do I purchase material after I’ve received a quote for the material?

The URL that allows you to view the quote you’ve generated on the vendor’s website will allow you to complete the purchase of the material on the vendor’s e-commerce website.
